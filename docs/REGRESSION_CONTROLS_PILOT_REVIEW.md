## Bounded independent-control proposal

Selecting one pytest node is currently insufficient: its module fixture
runs the entire worker, including thirteen complete model configurations,
fifteen closeout tails and ancillary component/staged networks.
The previously measured module took about 42 minutes.

1. Implement only an opt-in dart selector inside the existing worker and
   fixture. Resolve an allowlisted selected-node/control group before
   constructing recipes and tail definitions; preserve the full default
   path and existing assertion owners.
2. Dart needs the current complete cascade, AF66Good/AF66Closed tails and
   their existing helpers, not the other twelve complete models or
   unrelated tails. Reuse `compile_isolated`, `prepare_definition_image`,
   `batch_apply_down`, canonical `corpus_rows`/context loading, the raw
   `before` checkpoint and `entry_stages`. Unused Foma tail definitions
   must also be omitted: skipping only their export can retain their cost.
3. Keep the existing canonical and tail assertions and wrong-model check.
   Never substitute a cached trace for fresh canonical execution, silently
   fall back to an old receipt, or claim a focused run swept all 394 rows.
   Unknown selections, missing dependencies, rejection/ambiguity and stale
   required provenance must fail closed.
4. Reuse container-only `run_in_runner`, existing locking/exclusivity,
   budgets and `run_logged` source/argv/JUnit receipts. Record requested
   controls, executed assertion owners, model/tail/probe extent and
   focused/full mode without overwriting historical receipts. A focused
   pass certifies its declared extent only.
5. Verify focused/full slice equality, unchanged default behavior, stage
   and context resolution, unknown/missing references, wrong/omitted-model
   failures, stale provenance, rejection/ambiguity and truthful extent.
   Benchmark actual compilation count/time, then run ordinary full strict
   serial/exclusive validation because runtime semantics would change.

Only after that bounded implementation should another group or registry
binding be considered. Optional reporting precedes any mandatory adoption.
Use the existing registry, artifact graph, tests and controller; create no
alternative evaluator, compiler, chronology authority or source manager.
