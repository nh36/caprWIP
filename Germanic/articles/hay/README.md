# Old English hay article research handoff

This directory holds the hay article's source access records and, as of
research cycle 1 (2026-11-23), the first substantive research artifacts.

Source access:

1. `SC047_BASELINE.md` for the authoritative frozen A/B2 state.
2. `SOURCES.md` for acquisition and source identity.
3. `PASSAGES.tsv` for exact printed-page locators.
4. `UNRESOLVED.md` for the remaining substantive and evidence gaps.

Research artifacts (cycle 1):

- `LITERATURE_MATRIX.md` — comparative reconstruction of the published
  accounts (artifact A).
- `CONCORDANCE.tsv` — witness-level attestation concordance (artifact B).
- `PARADIGM.md` — grammatical-cell paradigm with evidence classes
  (artifact C).
- `QUANTITY_EVIDENCE.md` — quantity/syllabification evidence table with
  controls (artifact D).
- `DERIVATIONS.md` — explicit A0/A1/A2/B2 derivations from the frozen
  captures (artifact E).
- `DRAFT.md` — article draft: provisional introduction, Sections 2–3 in
  publishable prose, analytical scaffolding for 4–6 (artifact F).
- `RESEARCH_MEMO.md` — critical assessment and answers to the ten
  final-judgment questions (artifact G).
- `article_refs.bib` — research-scoped supplemental citations (Dahl1938,
  Hogg1979Analogy, Adamczyk2018, Dal1934, Ritt2000); `docs/refs.bib`
  remains authoritative for all keys it contains.
