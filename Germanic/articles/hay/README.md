This directory prepares source access only. It does not contain article
conclusions or propose executable changes.

Start with:

1. `SC047_BASELINE.md` for the authoritative frozen A/B2 state.
2. `SOURCES.md` for acquisition and source identity.
3. `PASSAGES.tsv` for exact printed-page locators.
4. `UNRESOLVED.md` for the remaining substantive and evidence gaps.

The source inventory is
`docs/references/hay-germanic-downloads-comprehensive-2026-11-22.tsv`;
the dated hay priority view is
`docs/references/hay-article-source-inventory-2026-11-22.tsv`.

No historical analysis, lexeme rule, data row, FST or book source has been
changed in this handoff.
