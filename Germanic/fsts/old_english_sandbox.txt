# This file MUST mirror germanic.txt exactly:
#   OldEnglishCore     = EnglishProtoInput .o. PGmcConsonantRules .o. EnglishProtoToOE
#   OldEnglishReflexes = OldEnglishCore .o. OEEpentheticVowel .o.
#                        OELateUnstressedAgSuffix .o. OECjCleanup .o. OEXsMerge .o.
#                        OldEnglishOrthography .o. OEGlideUToEO .o.
#                        OldEnglishRemoveStars .o. OldEnglishSurface
#
# Every rule that appears in that chain gets ITS OWN snapshot here. Bundles
# (PGmcConsonantRules, PWGmcChanges) are split open so each sub-rule is
# individually visible. Rule order matches the cascade exactly.

# shared with the Modern English pipeline and apply Modern-English-only rules
# (EnglishInitialKnMarkers, EnglishEarlyPalatalisation, EnglishWGlideRule,
# EnglishGhMarker, EnglishGlideDeletion) which are NOT in OldEnglishCore.
