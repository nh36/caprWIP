# Anti-patterns for lexeme-entry prose

These are banned or discouraged habits for the final book-style entry.

## Repository-centered phrasing

| Bad | Better |
| :--- | :--- |
| “The project keeps X as the lexeme label...” | “The comparative evidence points to X as the citation reconstruction...” |
| “The packet records that...” | “Bosworth-Toller records...” |
| “The current row targets...” | “The relevant Old English comparison form is...” |
| “The project moved through three stages...” | Omit project history from the final entry. Put it in the ledger or implementation report if needed. |

## Vague disagreement language

| Bad | Better |
| :--- | :--- |
| “There are disagreements in the reconstruction.” | “Orel gives *A, Kroonen gives *B, and Ringe & Taylor cite *C.” |
| “The handbooks disagree.” | “The sources differ in stem class, gender, and paradigm implications: X gives..., Y gives..., Z gives....” |
| “The source supports the form.” | “Clark Hall lemmatizes `sculdor`; Bosworth-Toller also attests `sculdrum`.” |

## AI-ish contrast and negation

| Bad | Better |
| :--- | :--- |
| “This is not X but Y.” | State Y directly. |
| “The disagreement is not merely graphic.” | “The disagreement affects stem class and expected inflection.” |
| “The winning form is not simply...” | “The decisive point is that...” or just state the reason. |
| “The comparison form needed here is therefore not... but...” | “The relevant comparison form is...” |

## Generic framing

| Bad | Better |
| :--- | :--- |
| “For the present derivation...” | State the form or claim directly. |
| “The crucial point is that...” | State the point directly unless emphasis is genuinely needed. |
| “This entry treats...” | “The evidence supports...” / “The comparison favors...” |
| “The current analysis...” | “The development...” / “The comparison...” |

## AI-ish prose to avoid

- repetitive negation;
- over-explicit contrast;
- generic summary endings;
- transitions that explain the document rather than the linguistic matter;
- vague signposting such as “the crucial point is” when the point can simply be
  stated.

## Where these notes belong instead

- **source ledger**: local file paths, discovery notes, missing citation keys,
  unresolved source matching, evidence vs inference notes
- **implementation report**: what was checked, what remained manual, what files
  were or were not changed
- **book-style entry**: the word, the forms, the sources, the Old English
  evidence, and the linguistic development
