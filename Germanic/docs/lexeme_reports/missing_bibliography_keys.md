# Missing bibliography keys

This file tracks sources needed by OE lexeme reports that do not yet have an
entry in `docs/refs.bib`.

## Current status

No missing bibliography keys recorded yet.

When a pilot report needs a source that lacks a key:

1. record the source here;
2. note where it was needed;
3. propose a key only after checking `docs/refs.bib` and
   `Germanic/docs/REFERENCES.md`.
