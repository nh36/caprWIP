## Development-note summary

No securely current **row-specific** DEV_NOTES note survives for row `2132`, so this slice must function as a replacement working note built from shared but still-current authority. The surviving DEV_NOTES material is nevertheless coherent: `*nabō-` is treated as the underlying Germanic lexeme meaning `'nave, hub'`, and the only substantial later discussion of the family repeatedly distinguishes that base lexeme from the separate `*-l-` derivative `'navel'` [Germanic/docs/DEV_NOTES.md:30196-30219,31034-31043; docs/references/kroonen_etymological_dictionary_pgmc.vision.txt:19998-20004; docs/references/orel_handbook_germanic_etymology.vision.txt:31422-31435].

For this row, the crucial distinction between **PROTO**, **PROTOFORM**, and **OE target** is straightforward and should stay explicit. `PROTO` and `PROTOFORM` are both `*nábō` because row `2132` is the base lexeme itself, not a row that needs a more explicit phonological surrogate input. The OE target `nafu` is therefore the direct OE reflex of the feminine `ō`-stem base word. Unlike row `2133` `nafola`, there is no `*-l-` suffix here, no inherited medial `*u` to encode between `b` and `l`, and no A-restoration problem to solve; importing the `navel` chronology into this row would blur two different lexemes [Germanic/data/germanic-aligned-final.tsv:784-784; Germanic/docs/DEV_NOTES.md:30216-30219,31034-31043,31473-31500].

The shared phonological doctrine that *does* survive is the project's Path A treatment of word-final bimoraic `*-ō`. DEV_NOTES states that "PGmc word-final bimoric non-nasalized long `*-ō` became short `*-u` in unstressed syllables in PNWGmc" and gives `*gebō → *gebu → OE giefu` as the model example [Germanic/docs/DEV_NOTES.md:2711-2719]. The later summary reiterates the same conclusion as handbook consensus: "Bimoraic final `*-ō → u`: All sources agree" [Germanic/docs/DEV_NOTES.md:3558-3558]. Row `2132` belongs to that same pathway: the live `PROTOFORM` `*nábō` should be read as the PGmc input, whose regular NWGmc/OE outcome after final-`ō` raising is `*nabu > nafu`, with final `-u` retained because the stem is light, just as Campbell's declensional treatment of `nafu` predicts [Germanic/docs/DEV_NOTES.md:2711-2719,3558-3558; docs/references/campbell_old_english_grammar.txt:15190-15201].

The comparative philological framing is also stable enough to preserve. Kroonen's `*nabō- f. 'nave'` entry gives `OE nafu`, `OHG naba`, and the modern Germanic reflexes, and DEV_NOTES' navel appendix independently restates the same etymological core: `PGmc *nabō- f. 'nave (of wheel)' (OE *nafu*, OHG *naba*) < the same *h₃nobʰ-eh₂-* as Latv. *naba*` [Germanic/docs/DEV_NOTES.md:31031-31035; docs/references/kroonen_etymological_dictionary_pgmc.vision.txt:20002-20004]. Orel agrees and immediately places `*nab(u)lōn` beside it as a derived formation from `*nabō`, which is useful precisely because it shows where the row boundary runs: `nafu` is the base lexeme, `nafela/nafola` the derivative [docs/references/orel_handbook_germanic_etymology.vision.txt:31422-31435].
