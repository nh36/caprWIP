## Development-note summary

The first distinction that later work has to keep explicit is the one between comparative dictionary headword, row-level derivational input, and OE target. The live row's **PROTO** and **PROTOFORM** are both `*táixōn`, a project-normalized form with accented stress and `x` for the velar fricative [Germanic/data/germanic-aligned-final.tsv:1276-1276]. That is not identical to Kroonen's lemma-style entry, which is quoted in the row-specific analysis as “`*taihwō(n)- ~ *taiwō(n)-` f. 'toe' ... `OE tā(he)` f. 'id.'” [Germanic/docs/analysis/four_complex_tsv_items.md:206-209; @Kroonen2013, p. 505]. It is also not identical to Ringe–Taylor's stage-specific reconstruction, likewise preserved in the analysis: “`PNWGmc *taihōn- 'toe' (ON tá, OHG zēha) > PWGmc *taihā > OE tāhe ... > tā`” [Germanic/docs/analysis/four_complex_tsv_items.md:211-214; @RingeTaylor2014, §6.1.2; §6.6]. For this row, `*táixōn` is the live modelling input; `tā` is the **COUNTERPART** actually targeted by the row; and `tāhe` belongs to the explanatory attestation chain and intermediate derivation, not to the current COUNTERPART slot.

The second distinction is between current shared DEV_NOTES authority and row-specific explanation that now lives mostly outside `DEV_NOTES.md`. No dedicated toe dossier currently survives in DEV_NOTES. The strongest current fragment that still bears on the row is the shared West Germanic monophthongisation note, which says the project inserted `EnglishSandboxWestGermanic` so proto `{*ai}` and `{*au}` collapse to historical `{*ā}` and `{*ō}`, making forms like `{*bān}` and `{*stān}` inspectable directly [Germanic/docs/DEV_NOTES.md:2259-2263]. That fragment is relevant because row `2259` begins with the same stressed-`*ai` development: the live trace's first step is exactly `*táixōn > *tāxōn` [Germanic/docs/debug_snapshots/oe_derivation_class_trace_report.with_lexeme_reports.publish.md:5368-5372]. But the fragment does **not** name `toe / tā`, does not discuss `tāhe`, and does not by itself justify the row's later `OE H Loss` plus `OE Contraction` stages. Later reports should therefore cite it only as shared phonological context, not as a row-dedicated toe note.

The row-specific explanatory material that does survive is concentrated in the linked analysis file and the live TSV note. That analysis preserved the key comparative contrast cleanly: Kroonen's `*taihwō(n)- ~ *taiwō(n)-` keeps the older labiovelar etymological shape, while Ringe–Taylor's `*taihōn-` removes the `-w-` and directly matches the OE chain `tāhe > tā` [Germanic/docs/analysis/four_complex_tsv_items.md:206-225; @Kroonen2013, p. 505; @RingeTaylor2014, §6.6]. It also documented an important now-superseded debugging stage: with corrected proto `taixōn`, the pipeline once reached `tāe`, which showed that monophthongisation, n-stem handling, and intervocalic `h`-loss were already working, while the final long-vowel-plus-suffix contraction still needed modelling [Germanic/docs/analysis/four_complex_tsv_items.md:235-275]. That older diagnosis should not be discarded, because it explains why the row note mentions both the TSV proto correction and contraction. But it is no longer the present row state. The current trace now includes `OE Contraction: *tā`, and the live row is classified `regular`, not left in an open mismatch bucket [Germanic/docs/debug_snapshots/oe_derivation_class_trace_report.with_lexeme_reports.publish.md:5372-5378; Germanic/data/germanic-aligned-final.tsv:1276-1276].

The safest replacement working note is therefore conservative. Row `2259` is presently stable and regular, the current row-level input is `*táixōn`, the current OE target is `tā`, and the best philological explanation still runs through Ringe–Taylor's chain `*taihōn- > *taihā > tāhe > tā` plus Kroonen's lemma-level evidence for `OE tā(he)` [Germanic/data/germanic-aligned-final.tsv:1276-1276; Germanic/docs/analysis/four_complex_tsv_items.md:206-233; @Kroonen2013, p. 505; @RingeTaylor2014, §6.6].
