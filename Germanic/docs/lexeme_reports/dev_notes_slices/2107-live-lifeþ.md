## Development-note summary

This row has securely attachable current DEV_NOTES authority, and that authority is explicitly row-local rather than merely generic class-III background. The live row is not trying to derive the OE lemma directly from the comparative infinitive. Instead it keeps `PROTO = *libēną` as the cognate-set headword, chooses `PROTOFORM = *líbēθi` / DEV_NOTES `*libēþi` as the selected finite 3sg present cell, and targets normalized OE `lifeþ`, with late Northumbrian `lifed` treated as the directly cited orthographic variant [Germanic/data/germanic-aligned-final.tsv:686; Germanic/docs/DEV_NOTES.md:4320-4374; Germanic/docs/lexeme_reports/research_memos/2107-live-lifeþ.md:39-47,62-69].

The philological reason for that split is the inherited class-III stem alternation. DEV_NOTES preserves Ringe-Taylor's paradigm table in which the infinitive `libban` belongs to the `*-ja-` stem with gemination, while the 3sg present `lifed` belongs to the `*-ai- (> *-ē-)` stem without gemination [Germanic/docs/DEV_NOTES.md:4093-4105]. That is why the row note and memo both insist that `libban` is real and conservative, but belongs to a different stem from the one the row is chosen to represent; meanwhile `lifian` is a later class-II-style lemma-level remodeling, not the inherited finite-stem reflex the row wants to preserve [Germanic/docs/DEV_NOTES.md:4112-4127,4157-4170; Germanic/docs/lexeme_reports/research_memos/2107-live-lifeþ.md:49-69].

The row-specific attestation logic is also explicit and should stay explicit. DEV_NOTES quotes Ringe and Taylor that `Except for late North. pres. indic. 3sg. lifed, which must be an archaism ... we find only class II pres. indic. 2, 3sg. and iptv. sg. forms`, and separately warns that Anglian `lifgu`, `lifgaþ`, and `lifgende` are innovations from secondary `*-ē- ~ *-ēja-` remodeling, not survivals of the original class-III paradigm [Germanic/docs/DEV_NOTES.md:4148-4155,4174-4189]. Later writing therefore should not treat every non-WS `lif-` form as equally probative: for this row, archaic Northumbrian 3sg `lifed` / normalized `lifeþ` is current authority, while the Anglian `lifg-` forms are background evidence about later remodeling only.

The checked project chronology matters because some visible DEV_NOTES lines are no longer current row policy. Earlier in the same row analysis, DEV_NOTES still marked the 3sg path `NOT TESTED` and said `Option 1 remains the strongest single-row solution`, meaning `*libjăną -> libban` [Germanic/docs/DEV_NOTES.md:4212-4218,4305-4314]. Later the file records the actual probe `libēþi -> lifeþ`, concludes that the pathway is regular, and adopts Option 2 [Germanic/docs/DEV_NOTES.md:4337-4374]. A still later implementation log briefly collapsed `PROTO` into `*libēþi`, but the live TSV and memo restore the better distinction between comparative `PROTO` and OE-facing `PROTOFORM` [Germanic/docs/DEV_NOTES.md:4603-4605; Germanic/data/germanic-aligned-final.tsv:686; Germanic/docs/lexeme_reports/research_memos/2107-live-lifeþ.md:87-95].
