## Development-note summary

This row is current precisely because the project stopped treating the mismatch as a sound-change failure and reclassified it as a lexeme-selection error. The live row now matches the regular class II weak-verb outcome `*súndrōjaną → sundrian`; the abandoned target `sundor-` belonged instead to the separate adverbial lexeme `*sunþraz > OE sundor`. DEV_NOTES preserves Orel's three-way split and it should stay explicit here: `*sunþraz` gives adverbial `sundor`, `*sunþrjanan` gives umlauted class I `syndrian`, and `*sunþrōjanan` gives class II `sundrian` [@Orel2003, pp. 386-387]. The row's `*súndrōjaną` / `*sundrōjaną` spelling is therefore not a rival analysis, only the project's orthographic spelling of the same class II verb.

The comparator evidence is likewise verbal, not adverbial. DEV_NOTES ties the cogset to Dutch `afzonderen`, English `sunder` (< OE `sundrian` / `āsundrian`), and German `sondern` (< OHG `suntarōn`), then quotes Kluge-Seebold directly: “Wie ae. gesundrian, anord. sundra … aus *sundarōn-” [@KlugeSeebold2011, p. 771]. That is the right comparative frame for row 2232. Hall and Bosworth-Toller also keep verbal `sundrian` / `(ā-)sundrian` distinct from adverbial `sundor`, so the corrected row should continue to present `sundrian` as the attested OE verb and `sundor` as a superseded, non-target detour [@ClarkHall1960; @BosworthToller1898].

For later report work, the regular comparator, attested outcome, and superseded project detour need to stay sharply separated. The regular comparator is exactly the row's current form: DEV_NOTES states that class II `*-ōjaną` with no class I `j`-suffix umlaut yields `sundrian`, and the FST already produced that result. The attested outcome is therefore `sundrian`, not a compromised or half-regular form. The superseded detour is `sundor-`, whose trailing hyphen and Wiktionary-derived provenance mark it as a bound-element/adverb extraction error rather than a serious OE verbal competitor.
