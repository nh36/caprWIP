## Exact corrections made

1. **`2087 knob / cnobba`**
   - Replaced the incorrect claim that the initial velar is lost in OE `cn-`.
   - Revised the development section so Proto-Germanic `kn-` is described as
     corresponding to OE `cn-`.
   - Sharpened the prose so `cnobba` is explicitly reconstructed, `cnoppa /
     cnopp` remain the attested voiceless-branch controls, and the comparator
     choice is presented as a modeling decision rather than settled OE
     philology.
   - Updated the checklist and implementation report so the entry passes only
     with a major human-review caveat.

2. **`2095 learn / liornian`**
   - Lightly expanded the dialect explanation using Campbell's statement that
     `leornian` has secondary `eo` while Northumbrian preserves `io` forms.
   - Reworded the comparison table to call `*líznōjaną -> liornian` a computed
     regular output and attested Northumbrian comparison form.

3. **`2296 withy / wīþiġ`**
   - Softened the suffix-development wording so Campbell's `*-ag- > -ig`
     account is presented as the analysis adopted here.
   - Reworded the ja-stem comparison so `*wīþja-` remains comparative
     background rather than a straw-man target.

4. **`2013 fire / fȳre`**
   - Added Bosworth-Toller to the source ledger and model entry for direct OE
     evidence of `fyr / fyre`.
   - Reduced the remaining rhetorical-negation wording in the OE evidence
     section.
   - Updated the checklist and implementation report to reflect the stronger OE
     evidence anchoring.

5. **`2273 wasp / wæfs` and `2300 wool / wull`**
   - Inspected only.
   - Left unchanged because no clear claims or citation error required a
     revision.
