# Historical lexical production records

This archive preserves pre-cleanup records from commit
`c06c896da21f50df756d91c9f5729511b910b8c9`, byte for byte. Paths below mirror
their former locations relative to `Germanic/docs/lexeme_reports/`.
For example, an old `model_entries/NAME.reviewer_checklist.md` citation now
resolves to `archive/model_entries/NAME.reviewer_checklist.md`.

These are mixed historical records, not content certified as redundant.
Original forms, quotations, rejected hypotheses, uncertainty, locator corrections,
review caveats and unsuccessful claims remain intact. A historical "pass",
"current" or "no blocker" never overrides today's evidence or scholarly judgement.
Relative references inside the preserved records use their original location;
resolve them there first, then apply this archive-prefix mapping if moved.
The original linked context is also available with `git show c06c896d:PATH`.

Current models and all source ledgers remain in `../model_entries/`; actual
source verification belongs there and in `../pgmc_reconstructions/`.
No ledger is retired or its verification upgraded by this archive.
The corrected Orel/Kroonen/Fulk folios and Toller Supplement identification
remain in their current evidence owners as well as the historical corrections.

The population crosswalk retains stable-ID links to archived research material.
Mechanical checklist/report files no longer count as active drafting evidence.
Use the single `../writing_skill/reviewer_checklist.md` for human review and
the existing citation, semantic, identity and assembly validators for mechanical
checks. New work records only meaningful evidence, decisions and limitations;
it need not create another paired implementation report and completed checklist.
