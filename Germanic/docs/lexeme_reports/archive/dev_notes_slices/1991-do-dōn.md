## Development-note summary

DEV_NOTES support for row `1991` is direct but compact. The surviving material does not present a long derivational investigation, because the project eventually concluded that there was no sound-change failure to solve. Instead, the important record is that the row had been mis-entered with short-vowel `don`, while the FST was already returning the historically correct long-vowel infinitive `dōn` [Germanic/docs/DEV_NOTES.md:9148-9179].

The earlier audit context matters because it shows how the problem first appeared. In the January mismatch sweep, `*dōną → dōn` versus expected `don` was listed among the normalized-distance-zero cases: a near-miss where the mismatch survived only after diacritic stripping, alongside other cases that DEV_NOTES classed as orthography/diacritic alignment rather than genuine phonological failure [Germanic/docs/DEV_NOTES.md:2618-2621]. That context is worth preserving because it explains why row `1991` looked like a long-vowel problem in aggregate reporting without actually motivating a new OE rule.

The March row-specific fix note then makes the project judgement explicit. DEV_NOTES says: “This was counted as a mismatch, but the FST was correct,” and grounds that judgement in Fulk's repeated long-vowel spelling of the verb: `"OE dōn 'do' and its WGmc. cognates"`, `"remarkable that the WGmc. simplex verb (OE dōn, OS dōn, duon, OHG tuon)"`, plus index listing `dōn` with long vowel [Germanic/docs/DEV_NOTES.md:9159-9166]. The same note states the substantive historical claim in compressed form: “The OE verb 'do' has a long vowel throughout its history, from PGmc `*dōną` (infinitive of an athematic verb) to OE `dōn`” [Germanic/docs/DEV_NOTES.md:9168-9169]. For replacement-note purposes, that is the core row-local conclusion to preserve.

So the working-note takeaway should stay narrow and explicit. Row `1991` is not a surviving irregularity, and the current `regular` label is not in tension with DEV_NOTES. The row's important history is that an older TSV target understated vowel length; the repair was a data correction (`don` → `dōn`, `d o n` → `d ō n`), not a new phonological derivation or an exception policy [Germanic/docs/DEV_NOTES.md:9171-9179].
