## Development-note summary

No securely attachable **row-specific** DEV_NOTES dossier survives for row `2173`. What survives instead is shared material that repeatedly treats `*satjan/*satjăną → settan` as a standard control example for the ordinary short-stem Class I weak-verb pathway. That is the right scale on which to read the row: not as a repair case, and not as a row whose current state depends on a late corrective memo, but as a regular lexeme supported by shared chronology and handbook-backed comparison [@Fulk2018, §6.15; @Campbell1959, §§190 ff.; @SieversBrunner1965, §227]. [Germanic/docs/DEV_NOTES.md:1750-1753,39155-39166].

The most explicit current DEV_NOTES statement is the January 2026 chronology check, which says that standard descriptions show WGmc gemination before `*j` in short stems and i-mutation after `*i/*j`, with the “classic paths like `*satjan > *sattjan > *sættjan > *settian > OE settan`” [@Fulk2018, §6.15; @Campbell1959, §§190 ff., 464; @SieversBrunner1965, §§95, 227]. [Germanic/docs/DEV_NOTES.md:1750-1753]. For row `2173`, that shared note is already enough to explain why the live target is `settan`: the OE `e` and geminate `tt` are not ad hoc spellings but the expected short-stem `*-jan-` outcome under the standard gemination-plus-umlaut chronology.

The rule ordering also needs to stay explicit. DEV_NOTES later summarizes the relevant order as WGmc consonant gemination before `*j`, then OE i-umlaut, then OE palatalisation of velars, and later still OE high-vowel apocope / `*j`-loss after heavy syllable [@Fulk2018, §6.15; @RingeTaylor2014, §§6.4.1-6.4.2; @Campbell1959, §§190 ff., 427 ff.; @SieversBrunner1965, §177]. [Germanic/docs/DEV_NOTES.md:39155-39166]. For `settan`, that matters because later writeups can otherwise flatten the development into a vague “umlaut plus gemination” shorthand. The shared DEV_NOTES chronology makes clear that the row belongs to the ordinary geminating `*-jan-` class and that its visible OE form is the expected endpoint of that ordered sequence.

The best philological contrast note comes from DEV_NOTES' Brunner excerpt. There the note says Brunner treats `*strawjan → strēgan` as a case of diphthong formation plus `j`-retention, “in contrast to the short-stem class-1 weak verbs (`nerian, settan`) where j is lost with prior consonant gemination” [@SieversBrunner1965, §129 Anm. 2; @SieversBrunner1965, §408 Anm. 12]. [Germanic/docs/DEV_NOTES.md:27171-27187]. That matters directly for row `2173`: the row belongs with the short-stem geminating verbs, so overt `j` is not expected in the OE infinitive, while the doubled consonant is.

DEV_NOTES also preserves one useful cross-row diagnostic. In the `fastian`/`festan` investigation, the note tests `*satjăną` precisely because it is a known regular control and records `Pipeline result: satjăną → settan ✓` [Germanic/docs/DEV_NOTES.md:4474-4544]. The surrounding argument there belongs to row `2004`, not row `2173`, so it should not be imported as current policy here. But the control-test itself is worth retaining because it shows that, inside DEV_NOTES' own debugging history, `settan` functioned as a positive witness that the ordinary short-stem gemination/umlaut pathway was already working.

One notation warning should remain explicit. The live aligned row writes `PROTO = PROTOFORM = *sátjaną`, while DEV_NOTES' shared examples use unaccented or working-notation forms such as `*satjan` and `*satjăną` [Germanic/data/germanic-aligned-final.tsv:2173; Germanic/docs/DEV_NOTES.md:1751,4540-4542].
