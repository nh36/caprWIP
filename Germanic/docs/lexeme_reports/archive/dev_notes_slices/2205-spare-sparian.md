## Detailed development-note summary

The working conclusion for this row is not that OE `sparian` continues Proto-Germanic class III unchanged, but that the inherited class-III cognate set was **refashioned early** into a class-II input before the row enters the FST. The comparative reconstruction remains class III `*sparēną` / `*sparēn-`, supported by ON `spara`, OHG `sparēn`, and the mixed Northumbrian relics; the row-level project input is instead class II `*spárōjaną`, because that is the shape from which the FST actually reaches the attested OE citation form `sparian` [@Kroonen2013, p. 465; @Orel2003, p. 363; @Campbell1959, §764; @RingeTaylor2014, pp. 162, 191; Germanic/data/germanic-aligned-final.tsv:1066-1066].

Older DEV_NOTES material first reached the row through a mismatch state. In that earlier state, row `2205` still used class-III `*spárēną` as the FST input, and DEV_NOTES correctly diagnosed the central morphological problem: “PROTOFORM is the class-III form `*spárēną` but OE `sparian` is class II.” The same note preserved Campbell's crucial quotation that the Ritual evidence “suggest Prim. OE forms both with and without back vowels in the syllables after the root syllable, hence conjugation according to Class II or Class III” [Germanic/docs/DEV_NOTES.md:36483-36504; @Campbell1959, §764]. That diagnosis remains useful as project history, but not as the live row state, because the live TSV has already made the PROTOFORM switch.

The later closure note contains the current substantive decision. It surveys the attested Anglian relics and concludes that none gives an admissible row target under the project's “longest lautgesetzlich span” rule. DEV_NOTES preserves the decisive anti-apocope point from Brunner: “Ein Abfall anderer Endsilbenvokale … findet im Ae. nicht statt … insbesondere bleiben erhalten: auslautende -e (für älteres -i oder -æ),” and immediately adds Campbell's corroborating Anglian imperatives `hæfe, sæġe`; on that basis, Ritual `spær` cannot be a regular phonological continuation of `*spárē` but must be analogical, probably under pressure from adjective `spær` < `*sparaz` [Germanic/docs/DEV_NOTES.md:37874-37881; @SieversBrunner1965, §150; @Campbell1959, §766; @RingeTaylor2014, p. 162]. This matters because it rules out the tempting “late analogy” solution in which a class-III PGmc input would be kept and OE `spær` or `spære` treated as the row's better witness.

The adopted row policy is therefore the “very-early analogy” option. DEV_NOTES states that the class-III → class-II refashioning is taken at the `(West-)Germanic → pre-OE` stage, that TSV `PROTOFORM *spárōjaną` is a strict transponent, and that the FST then derives `sparian` regularly from that shape just as it does for other class-III→II remade `-ian` verbs such as `búrōjaną → borian`, `líznōjaną → liornian`, `xándlōjaną → handlian`, and `súndrōjaną → sundrian` [Germanic/docs/DEV_NOTES.md:37883-37914; @RingeTaylor2014, p. 191]. For row `2205`, that is the operative current rationale: `PROTO` remains the inherited cognate-set label `*sparēną`; `PROTOFORM` is the pre-OE class-II transponent `*spárōjaną`; `COUNTERPART` remains OE `sparian`.

One part of the closure note is now explicitly stale and must not be copied forward as current fact. DEV_NOTES says the “TSV change actually applied” changed both `PROTOFORM` and `PROTO` to `*spárōjaną`, but the live row no longer does that: only `PROTOFORM` is `*spárōjaną`, while `PROTO` remains `*sparēną` [Germanic/docs/DEV_NOTES.md:37916-37924; Germanic/data/germanic-aligned-final.tsv:1066-1066]. That stale line is still useful as chronology because it explains why older packet/memo material warns against collapsing the etymological proto into the transponent, but it is not live row authority.

On present evidence this row is stronger than a mere no-index placeholder. The current row has one clean, row-specific DEV_NOTES decision fragment (`37883-37914`) plus one still-useful diagnostic fragment for the pre-switch mismatch (`36483-36504`), even though the application log at `37916-37924` is partly superseded by the later restoration of `PROTO *sparēną`. A final report should therefore treat the row as: inherited class-III cognate set, early class-II remodelling as project input, canonical OE citation-form target `sparian`, and Anglian Ritual material as historically important but non-target evidence [Germanic/docs/DEV_NOTES.md:36483-36504,37874-37924].
