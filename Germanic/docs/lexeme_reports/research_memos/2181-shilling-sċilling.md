## Reconstruction and early-stage forms

The crucial distinction is three-way.

1. **Cognate-set / etymological proto in the sources.** Kroonen is cited in the row note as `*skellinga- ~ *skillinga-`, and the older analysis file also discusses a more explicit etymological interpretation `*skeld-linga-` under the shield-word family. That is useful philological background about the larger cognate set, but it is not the exact project input form.
2. **Project input form.** The live row uses **`*skíllingaz`** as a parsable nominative singular PGmc input with overt `-ingaz`. This is the form the FST now accepts and derives correctly.
3. **OE target form.** The row's target is the OE citation form **`sċilling`**, i.e. the bare nominative singular masculine a-stem form after loss of final `-az`.

So the current project solution is not "the etymological proto is solved once and for all as `*skíllingaz`." Rather, the project has chosen `*skíllingaz` as the correct **modelling input** for this row because the older `*skéllinaz` was simply wrong for the OE target and because the derivational suffix `-ing-` is required by the cognates and the OE form.

## Old English philology

`sċilling` is the OE headword/citation form, not a special inflected cell requiring analogical rescue. The important philological point is the retention of **`-ing-` with `i`**, not `-eng-`. `DEV_NOTES` §17.35 and the dossier align with the standard handbook view that OE derivational suffixes such as `-ing` preserve unstressed `i`; the live fix therefore brings the model into line with normal OE philology rather than creating an exception.

The form should be treated as an attested OE lexical item/headword, while the exact PGmc preform behind the cognate set remains a separate etymological question. Nothing in the repo research supports rewriting the OE target away from `sċilling`, and nothing here requires a dialectal or manuscript-specific claim beyond the ordinary dictionary headword status already assumed in project materials.

## Project problem and solution

The project problem was originally twofold:

- the row had a bad modelling proto (`*skéllinaz`), which omitted the derivational `-ing-` morphology needed for `sċilling`;
- even after correcting the input to `*skíllingaz`, the FST initially lacked the `*-ingaz` weak-tail shape and then wrongly lowered medial unstressed `i` before `*ng`, producing `*-eng`.

That problem is now solved. The row should be understood as a **regular** OE output from the project's chosen PGmc input `*skíllingaz`, with the note serving mainly as change history and philological justification. The older "documented exception / compound too hard to parse" storyline is superseded for this row as currently implemented.

The final `### Lexeme report` should be brief and should center on one point: the row used to carry the erroneous modelling proto `*skéllinaz`, but the live project now correctly models OE `sċilling` from `*skíllingaz`, with `-ing-` justified by the cognates and by standard OE preservation of derivational `-ing` with `i`. It should explicitly distinguish the wider etymological discussion (`*skellinga- ~ *skillinga-`, possibly `*skeld-linga-`) from the narrower project input form.
