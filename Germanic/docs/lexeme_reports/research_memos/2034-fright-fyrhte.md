## Reconstruction and early-stage forms

This row requires a strict three-way distinction.

- **Cognate-set proto / etymological headword:** `*furxtīn-`, the in-stem abstract reflected by Goth. `faurhtei`; this is the level represented by TSV `PROTO`.
- **Project input form used for derivation:** `*fúrxtīnaz`, the PGmc gen.sg. selected as the row’s explicit derivational input; this is TSV `PROTOFORM`, not the lexeme headword.
- **OE target represented by the row:** `fyrhte`, an attested oblique OE form, not the citation-form nominative.

The earlier `*furhtiþō/*fúrxtiθō` analysis is no longer defensible as current project evidence. Orel gives `*furxtīn`; the later `DEV_NOTES` sections explicitly diagnose `*fúrxtiθō` as a TSV hack that had been introduced to force `fyrhtu`. The current row instead treats the lexeme as an in-stem and chooses one oblique cell whose full tail exercises the repaired chronology.

The early-stage sequence behind the live row is therefore: lexeme stem `*furxtīn-` > selected gen.sg. `*fúrxtīnaz` > post-z-loss / post-apocope `*fúrxtīn` > suffixal `*-īn` reduction and OE developments > `fyrhte`. That is different from both the older cognate-set discussion of nominative `fyrhtu/fyrhto` and the stale `*iþō` workaround.

## Old English philology

Philologically, the row is about the gap between the dictionary lemma and the best project target cell.

- Orel, Ringe & Taylor, and Campbell support an in-stem analysis behind OE `fyrhtu/fyrhto`, not a primary `*iþō` abstract.
- Ringe & Taylor treat `fyrhtu` as part of the in-stem abstract group whose nom.sg. `-u` spread analogically.
- Campbell §459.3 and Brunner treat metathesized `fryhto/fryhtu` as a late and dialectally limited development; it is not the regular form the project should privilege.
- Clark Hall gives `fyrhto, fyrhtu (fryht-)` as the dictionary entry, while Bosworth-Toller also records oblique `fyrhte` (e.g. Guth. 88,18; 92,1), exactly the cell the TSV now targets.

So the row should not imply that `fyrhte` is the ordinary citation form. It is an attested oblique cell chosen because the bare-stem nom.sg. `*fyrht` is treated in the current project as unattested and because the analogical nominative in `-u` belongs to later paradigm remodeling. The OE target is therefore attested, but it is not the lemma-headword form found in dictionaries.

## Project problem and solution

The project problem was never just “what is the right proto?” It was “which OE form should the row represent once the `*iþō` workaround is abandoned?”

The repo’s chronology shows three stages:

1. an older hacky solution using `*fúrxtiθō` to force `fyrhtu`;
2. an interim “honest phonology” proposal to retarget the row to unattested bare-stem `fyrht`;
3. the current solution: keep the in-stem lexeme, choose an attested oblique input/output pair, and target `fyrhte`.

The present solution is the best one in the repo:

- it keeps the philologically better lexeme reconstruction `*furxtīn-`;
- it keeps `PROTOFORM` as a real PGmc surface form rather than a post-apocope convenience form;
- it avoids pretending that analogical nom.sg. `fyrhtu` is the direct phonological output of the chosen input;
- it avoids targeting unattested `*fyrht`;
- and it anchors the row in attested OE `fyrhte`.

`late_analogy` still makes sense as the project label, not because `fyrhte` itself is analogical, but because the row exists within a paradigm whose better-known nominative forms underwent later remodeling and because the project is intentionally targeting a non-lemma cell to avoid that remodeled nominative problem.

## Paradigm probe

A paradigm probe is **required in principle** for this row, and the current repo already has the necessary probe. The live note and `DEV_NOTES` `§17.45.3d–g` show that these cells were tested against the repaired cascade:

- gen.sg. `*fúrxtīnaz`
- dat.sg. `*fúrxtīni`
- acc.sg. `*fúrxtīnų`
- nom.pl. `*fúrxtīniz`
- post-apocope stem form `*fúrxtīn`

The current result is that all five now converge on `fyrhte`. That is enough for the lexeme memo; no additional lexeme-specific probe is missing. If the final report includes a probe table, it should reuse exactly those cells and explicitly note that the nominative lemma forms `fyrhto/fyrhtu/fryhtu` are a separate morphological issue, not the direct target of this row.

Recommend a concise final report that foregrounds the current three-way distinction: lexeme-level `*furxtīn-`, row-level derivational input `*fúrxtīnaz`, and OE target `fyrhte`.
