## Reconstruction and early-stage forms
The key distinction is between the cognate-set headword and the row's actual derivational input. `*kōz` is the inherited nominative singular and correctly belongs in TSV `PROTO`. `*kūi` is the PGmc dative singular cell and correctly belongs in TSV `PROTOFORM`. Kroonen's root-noun ablaut `*kō- ~ *kū-` explains that split. Ringe–Taylor's discussion of a later leveled nominative `*kūaz/*kūz` is relevant background for the history of OE `cū`, but the current row does not need to rest on that more complex nominative history because the dative already gives a clean regular path to attested `cȳ`.

## Old English philology
`cȳ` is an attested OE form, but it is not the default lexical headword; dictionaries cite `cū`. R/T explicitly identify `cȳ` as the dat.sg. and also the nom.-acc. plural reflex of the zero-grade stem with i-umlaut. Because the same surface form serves multiple cells, the row's `*kūi` input is important: it makes clear that the TSV is intentionally encoding the dative singular cell, not claiming that `cȳ` is the ordinary lemma.

## Project problem and solution
The earlier project state had two separate issues: the spurious nominative reconstruction `*kōwz`, and a pipeline limitation that gave `kūi → cȳe` instead of `cȳ`. The later investigation fixed both. It restored the proper headword `*kōz`, chose the dat.sg. `*kūi` as the OE row's actual test cell, and then documented the small FST fix needed for root-noun vowel hiatus so that `kūi → cȳ` now works cleanly. The current row is therefore not just a theoretical recommendation; it is the implemented and verified solution.

## Paradigm probe
A fresh probe is optional, since `cow_root_noun_investigation.md` already lays out the relevant paradigm and the implemented fix. If one is created for the eventual report, it should include nom.sg. `*kōz`, dat.sg. `*kūi`, nom.-acc.pl. `*kūiz` (or the competing reconstruction discussed in the analysis), dat.pl. `*kūmaz`, and a caution that the gen.sg. evidence is more uncertain than the dative.

## Recommended final report
Recommend a concise final report that says row 1980 is a deliberate oblique-cell solution: TSV `PROTO` keeps the inherited nominative headword `*kōz`, but the row itself targets dat.sg. `*kūi → cȳ` because the citation form `cū` reflects later leveling and is not the cleanest sound-law test.
