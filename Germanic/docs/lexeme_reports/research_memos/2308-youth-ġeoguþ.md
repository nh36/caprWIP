## Reconstruction and early-stage forms

This row needs a strict three-way distinction.

1. **Cognate-set proto / etymological headword:** the handbook-level etymology is Kroonen's `*ju(w)unþi-` 'youth', ultimately from PIE `*h₂iu-H-ti-` [@Kroonen2013]. That is earlier and more etymological than the live TSV spelling.
2. **Project cognate-set label and input staging:** the live row uses g-bearing `*júgunθiz` / `*júgunθ-`, i.e. a post-velarization project form for the NWGmc/Ingvaeonic branch. Later `DEV_NOTES` explicitly recommends this lexical-specification strategy for `geoguð`-type items rather than adding a productive Bugge rule.
3. **Project derivational input:** TSV `PROTOFORM = *júgunθ` is the deliberately truncated, post-`-z`-loss, post-early-apocope input. It is not the full etymological headword; it is the form the OE cascade is meant to see.
4. **OE target:** `ġeoguþ`, the lemma/citation form represented by this row, with `iugoþ/iuguþ` as spelling variants rather than separate row targets.

The live row's strongest phonological point remains the early loss of final `-i` in `*-unþi-`. Ringe-Taylor's sequence `*jugunþi > *juguþ > OE geoguþ ~ iuguþ` and Campbell's `duguþ ... and so geoguþ` show why the row does **not** feed OE i-umlaut from a still-present final `-i` [@RingeTaylor2014; @Campbell1959]. The row's `PROTOFORM` therefore correctly encodes a stage after that loss, while the memo should still acknowledge the earlier scholarly headword with `-w-` and `-i-`.

## Old English philology

Philologically, the target is straightforwardly OE `ġeoguþ`, but the memo should keep several distinctions clear.

- **Attested vs. reconstructed:** `ġeoguþ` is attested; `*juguþ` is only the reconstructed pre-OE/PWGmc stage used to explain the lack of umlaut; `*ju(w)unþi-` is the earlier comparative reconstruction [@Kroonen2013; @RingeTaylor2014].
- **Citation form vs. variant spellings:** Campbell's `iugup/giogup/geogup` and Ringe-Taylor's `geoguþ ~ iuguþ` show orthographic and dialectal variation around the same lexeme, not competing lexical targets [@Campbell1959; @RingeTaylor2014].
- **Morphological contrast:** `ġeoguþ` behaves unlike genuinely i-containing abstract formations such as `fyrhtu`, where the suffixal `i` is still phonologically active enough to trigger umlaut. That contrast is why `fryhtu_investigation.md` is useful background rather than a rival analysis.
- **OE paradigm status:** repo-local notes give nom.sg. `ġeoguþ` and oblique `ġeoguþe`; nothing in the checked repo material suggests that this row should be retargeted to a different paradigm cell.

The final report should therefore say that `ġeoguþ` is an attested OE lexeme with spelling variation, but that the row's philological problem lies in pre-OE staging, not in uncertainty about which OE form to target.

## Project problem and solution

The project problem has two linked parts.

1. If the row feeds the full `*-i(z)` form too late into the OE cascade, the word is over-umlauted and yields the wrong `y`-type outcome.
2. Once the final `-i` is removed, the project still has to explain why the second `u` stays `u` in `ġeoguþ` instead of lowering to `o`.

The live project solution is now coherent:

- keep the row as a lexically specified g-bearing item rather than asking the cascade to derive `g` productively from `w`;
- use `PROTOFORM = *júgunθ` so that early i-apocope is already encoded before the OE umlaut stage;
- derive `ġeoguþ` by regular OE developments from that stage;
- explain medial-`u` preservation through progressive stem-`u` harmony, with Brunner and Luick as the decisive repo-backed authorities, rather than through the earlier provisional open/closed or suffix-final-only heuristics.

`early_analogy` remains a reasonable project label because the row still depends on a pre-applied early-stage transponent input rather than on a fully productive cascade from the earliest comparative headword.

## Paradigm probe

A dedicated paradigm probe is **not required** for this row.

This is not a `late_analogy` or paradigm-cell-selection case like `heofon` or `fyrhte`. The core issue is derivational staging (`*ju(w)unþi-` vs. project `*júgunθ`) and the chronology of apocope and unstressed-`u` preservation, not uncertainty about which OE paradigm cell the row should represent.

The absence of a row-specific entry in `oe_paradigm_probe.py` is therefore not a blocker. If the team later wants a sanity check, the only optional cells worth probing would be the citation-form `*júgunθ -> ġeoguþ` and the oblique extension `*júgunθe -> ġeoguþe`; but that would be confirmatory, not necessary for the memo's recommendation.

## Recommended final report

Recommend a concise final report that foregrounds the three-way distinction between scholarly `*ju(w)unþi-`, the row's g-bearing project staging (`*júgunθiz` / `*júgunθ`), and OE `ġeoguþ`. It should treat early i-apocope as the reason umlaut does not apply, treat medial-`u` preservation as stem-`u` harmony backed by the later dossier work, and explicitly label the mid-project open/closed-syllable discussions as superseded project history. It should mention `iugoþ/iuguþ` only as OE spelling variation, not as a different row target.
