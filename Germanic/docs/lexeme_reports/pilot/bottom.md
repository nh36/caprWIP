#### Project problem and solution

This is an `early_analogy` case. If the project fed the citation proto `*búdmaz` directly into the FST, the resulting outcome would not reflect the stem reshaping implied by the Old English evidence and the project note. Using `*búttmaz` as `PROTOFORM` makes the analogical prehistory explicit while leaving the cognate-set headword untouched.
