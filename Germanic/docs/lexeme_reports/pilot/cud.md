### Lexeme report

#### Reconstruction and early-stage alternatives

`cud` is an `attested_variant` pilot because the row disentangles a reconstruction problem from an Old English philology problem. The project note records a correction from older `*kwíθuz` to `*kwéðuz`, aligning the row with the e-grade / Verner-law analysis reflected in [@Kroonen2013], [@Orel2003], and [@RingeTaylor2014]. The crucial point is that the report should not treat the Old English target as a reconstructed convenience form; it is an attested conservative variant within a wider OE variant set.

#### Old English philology

The aligned row deliberately targets `cwedu`, identified in the note as a conservative West Saxon e-grade form. The same note distinguishes it from leveled `cwidu`, Anglian-type `cweodu`, and later rounded or de-labialized spellings. This is therefore a genuine attested Old English form, but not necessarily the most ordinary normalized dictionary headword across all dialects and periods.

#### Project problem and solution

This is an `attested_variant` case. The FST is not being asked to produce a speculative or unattested form. It is being asked to produce one real Old English variant that best preserves the inherited etymological structure. The report should therefore say that `cwedu` is an attested conservative target chosen from a broader philological field, not a claim that the other variants are "wrong."
