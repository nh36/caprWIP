# Source ledger — 2344 filter / sēoh

| Source | Reading and use |
| :--- | :--- |
| Seebold 1970 pp. 389–390; Ringe and Taylor 2014 pp. 178–179, 344–345 | Comparative long-grade citation and voiced participle. The accent and `xw` notation are CAPR's. |
| Orel 2003 pp. 329–330; Kroonen 2013 pp. 435–436 | Original page images distinguish the macron in Orel's *sīxwanan* from unmarked *i* in Kroonen's *sihwan-*. Neither is an attestation of the command. |
| Cockayne, *Leechdoms* II.24.1 and III.14.18, via Bosworth–Toller 27502 | *Seóh þurh cláþ* is a simplex imperative with final h. The transduced historical input is reconstructed from the comparative long root and endingless imperative, not a full form attributed to the dictionary. |
| Campbell 1959 pp. 186–187 §464; Ringe and Taylor 2014 pp. 48–49 | Final dorsal retention and the separate early loss of final labialization; no inference that the medial change applies to the selected imperative. |
| Exeter Book, *Christ* C 1086 (Thorpe p. 67 l. 13 / 1088 in Bosworth–Toller 40126) | Digital Exeter Book Hand transcribes *biseon mid swate*. The clause already has finite *stondeð*: *biseon* describes *rod*, alongside *bistemed*. Do not use this token as a verified infinitive. The dictionary specifically lists the token among participles in the *seón* entry. |
| Cockayne II.26.11, 124.14, via Bosworth–Toller 27502 and Seebold p. 389 | Distinct voiced prefixed grade. *Aseownes* is an inflected participial modifier; *asiwen* is participial in a passive construction. |
