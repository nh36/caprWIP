   `Kurath 1956` bibliography issue, and the paradigm comparison remains manual.

   so the selected paradigm-cell solution should be read as narrower than a
   full lexeme history.

   label `early_analogy`, and the older source split over medial `u` remains
   real in the background.
4. `2134 neck / hnecca` — the comparative label `*xnákkaz` remains weaker than
   the e-grade derivational input used in the entry, and the TSV still lacks a
   note for that distinction.
5. `2140 night / niht` — the argument still depends on a manual paradigm
   comparison, and promotion should re-check the balance between `niht` and the
   wider `neaht`-type variation.
6. `2143 nose / nosu` — promotion should re-check the balance between attested
   `nosu` and the parallel `nasu` tradition, as well as the distinction between
   the comparative headword and the remodeled input.
7. `2152 rest / ræste` — the argument still depends on a manual paradigm
   comparison, and the current source stack gives special prominence to the
   genitive label even though a broader oblique singular also converges on
   `ræste`.
8. `2162 rust / rust` — the central result remains that the citation-form
   development is unexplained; the competing citation reconstruction `*rustaz`
   is philologically important but not a solution.
9. `2168 sap / sæp` — the comparative stem history remains mixed across
   Kroonen, Orel, and Kluge-Seebold, and the inferred i-stem comparator should
   stay review-sensitive.
