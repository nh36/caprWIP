# Source ledger — 2343 see / sēon

| Source | Reading and use |
| :--- | :--- |
| Ringe and Taylor 2014 pp. 48–50, 178, 315–317 | Inherited unit labiovelar, PWGmc `*sehwan`, subsequent dorsal and hiatus stages; PGmc infinitive supplies the complete input. CAPR adds a primary accent and writes `xw` for the inherited labiovelar. |
| Kroonen 2013 s.v. *sehwan-*; Seebold 1970 pp. 387–388 | Comparative lemma and daughter spellings. Neither dictionary notation nor common semantics requires positing an OE prefix. |
| Bosworth–Toller, s.v. *seón*, entry 27500 | The quotation from Old English Boethius 38.5 (Fox 206.21) reports simplex *seón* after *mǽge* with a prefixed Cotton variant. The witness is checked in the dictionary citation, not recollated from the manuscripts. |
| Bosworth 1859 p. 52 | Old English Orosius citation *tō seonne*. This oblique infinitive supports the simplex verb but is not the selected inflection. |
| Ringe and Taylor 2014 pp. 344–345; Campbell 1959 §§461, 464 | Alternation with final dorsal and voiced medial grades; establishes why the inflected controls are not all singleton positives. |
