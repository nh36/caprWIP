## 5. Current SC022 rule body (to be replaced)

`Germanic/fsts/germanic.txt` (define `PNWGmcMnDissimilation`, ~line 2151):

```foma
define PNWGmcMnDissimilation [
    {*m} -> {*β} || EnglishStarVocalic _ EnglishStarVocalic EnglishStarConsonant* EnglishStarNasal
];
```

This is the broad cross-syllable **`mV…n` proxy** (an intervocalic `*m` before a
later nasal). It labializes an intervocalic `*m` — a **simulation of paradigm
levelling**, not the historical adjacent-cluster sound change. It fires on
exactly one corpus row (heaven). The dossier (§10, §13, §14) rejects it as a
*sound law* and prescribes the literal adjacent-`mn` rule.

**Planned replacement (validated in shadow work, §13.4/§14.2):**

```foma
define PNWGmcMnDissimilation [
    {*m} -> {*β} || EnglishStarVocalic _ {*n}
];
```
