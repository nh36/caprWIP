# SC002 PGmc Gm Simplification — literature dossier

## Historical phenomenon

This dossier concerns loss of `*g` before `*m` in the small lexical family represented in the inventory by `dream` and `team`.

## CAPR rule

- change_id: `SC002`
- display_name: `Gm Simplification`
- rule_name: `PGmcGmSimplification`
- FOMA definition: `*g -> 0 || _ *m`

## Example lexemes

1. `dream`
2. `team`

## Source support found so far

1. Kroonen derives OE `dream` from `*draugma-` and OE `tēam` from `*tauma-`, explicitly adding that `*taugma-`, like `*drauma- < *draugma-`, lost its `*g` [@Kroonen2013, pp. 101, 511].
2. Orel independently supports the dream family through `*draumaz` [@Orel2003, p. 114].

## Missing source support

1. No broader comparative-grammar or handbook discussion of Proto-Germanic `*gm > *m` was recovered in this pass.
2. The current source base is therefore lexical and etymological rather than a full phonological discussion.
