# SC011 Syllabic j after final-vowel loss — literature dossier

## Historical phenomenon

This dossier concerns the development by which postconsonantal `*j` becomes syllabic `*i` after the loss of final unstressed `*a` and `*ą`.

## CAPR rule

- change_id: `SC011`
- display_name: `PWGmc Syllabic J`
- rule_name: `PWGmcSyllabicJ`
- FOMA definition: `*ja, *ją -> *i` after a short vowel plus single consonant

## Example lexemes

1. `army`
2. `end`
3. `herdsman`
4. `kingdom`

## Source support found so far

1. Ringe and Taylor state directly that after the loss of unstressed `*a` and `*ą`, preceding postconsonantal `*j` became syllabic `*i` [@RingeTaylor2014, p. 46].
2. Their examples include `*harjaz > *hari`, `*andijaz > *andi`, and `*rikija > *riki` [@RingeTaylor2014, p. 46].
