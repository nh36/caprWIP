# SC013 Dental hardening — literature dossier

## Historical phenomenon

This dossier concerns the hardening of voiced dental fricative `*ð` to stop `*d`.

## CAPR rule

- change_id: `SC013`
- display_name: `PWGmc Dental Hardening`
- rule_name: `PWGmcDentalHardening`
- FOMA definition: `*ð -> *d`

## Example lexemes

1. `lade`
2. `needle`
3. `find`
4. `cud`

## Source support found so far

1. Ringe and Taylor state directly that in PWGmc the non-coronal voiced obstruents retained allophony but `*d` became a stop in all positions [@RingeTaylor2014, p. 43].
