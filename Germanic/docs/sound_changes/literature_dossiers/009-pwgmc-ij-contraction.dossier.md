# SC009 Ij-contraction — literature dossier

## Historical phenomenon

This dossier concerns the contraction of `*ijo` to `*iu` in the `friend` family.

## CAPR rule

- change_id: `SC009`
- display_name: `PWGmc Ij Contraction`
- rule_name: `PWGmcIjContraction`
- FOMA definition: `*ijō -> *iu` before a following consonant, with stressed and unstressed variants

## Example lexemes

1. `friend`

## Source support found so far

1. Ringe and Taylor describe a change of `*ijo` to `*iu` in `friend`, with the pathway PGmc `*frijond-` > PWGmc `*friund` > OE *friond* [@RingeTaylor2014, p. 62].
2. The same source immediately warns that the sequence `*ijo` is unique enough that broader generalization is inadvisable [@RingeTaylor2014, p. 62].

## Source gaps

1. The present source base is effectively one lexical family.
2. The current pass did not recover a broader comparative discussion that would justify a wide phonological rule independent of that family.
