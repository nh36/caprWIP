Inputs are in CAPR notation (an initial reconstruction asterisk is implicit); A/B columns are **regular executable predictions**, not transcriptions or alternative corpus targets. Unless marked otherwise, the input was admitted by both arms. **Yes** means a plausible historical discriminator only if the inherited cell can be identified before transfer. **Conditional** means class or downstream history must first be established. **—** means no lookup/output or no verified token, as indicated. A protected donor supplies a stem, not proof that it spread.
