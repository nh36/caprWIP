# SC010 West Germanic j-gemination — book dossier

## Historical phenomenon

SC010 isolates consonant gemination before `*j` after a short vowel in West Germanic.

## Relevant CAPR rule

- `PWGmcJGemination`
- consonant doubling before `*j` after a short vowel

## Example lexemes

1. `hedge`
2. `net`
3. `set`
4. `sit`
5. `will`

## Source support found so far

1. Fulk treats gemination before `*j` as regular after a short vowel and gives a substantial lexical set [@Fulk2018, §6.15].
