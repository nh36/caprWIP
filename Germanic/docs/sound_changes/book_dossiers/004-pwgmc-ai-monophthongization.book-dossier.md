# SC004 PWGmc ai-monophthongization — book dossier

## Historical phenomenon

SC004 isolates the West Germanic monophthongization of inherited `*ai`, especially its widespread unstressed reflexes and the special word-final outcome that merges with long mid `*ē`.

## Relevant CAPR rule

- `PWGmcAiMonophthongization`
- `*ai -> *ē` word-finally; otherwise `*ai -> *ā` and `*ái -> *ā`

## Example lexemes

1. `bone`
2. `deal`
3. `dough`
4. `flesh`
5. `ghost`

## Source support found so far

1. Ringe and Taylor give direct support for the unstressed `*ai` side through dat.sg., subjunctive, and plural endings [@RingeTaylor2014, pp. 40--41].
2. Fulk treats unstressed `ai` and `au` as part of the North/West-Germanic shared vowel developments [@Fulk2018, §5.2].
