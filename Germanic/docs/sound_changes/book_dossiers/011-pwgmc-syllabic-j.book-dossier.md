# SC011 Syllabic j after final-vowel loss — book dossier

## Historical phenomenon

SC011 isolates the development of postconsonantal `*j` to syllabic `*i` after final unstressed `*a` or `*ą` was lost.

## Relevant CAPR rule

- `PWGmcSyllabicJ`
- `*ja, *ją -> *i` after a light syllable

## Example lexemes

1. `army`
2. `end`
3. `herdsman`
4. `kingdom`

## Source support found so far

1. Ringe and Taylor state the rule directly and give several examples [@RingeTaylor2014, p. 46].
