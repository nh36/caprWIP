## Chronology statement
Write 2–4 sentences in a concrete derivational style.

Each card must include:

- the Proto-Germanic input form;
- the expected Old English output;
- the incorrect variant output;
- the crossed rule that creates the chronology constraint;
- a short explanation of why the wrong output results.

Do **not** write only a gloss-based statement such as “this rule must follow X because belly and cow fail.” Modern English glosses are useful identifiers, but the chronology prose must state the derivational contrast explicitly.
