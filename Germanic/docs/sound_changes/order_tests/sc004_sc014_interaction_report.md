# SC004 / SC014 formal interaction analysis (corrected PROTOFORM pass)

Generated by `tools/sc004_interaction_analysis.py` (data in
`sc004_sc014_interaction_analysis.tsv`). For the two corrected production rules

* SC014 `PNWGmcUnstressedAiMonophthongization` : `{*ai} -> {*ē}` (pos 1)
* SC004 `EAFAiMonophthongization` : `{*ái} -> {*ā}` (pos 25)

each pair is tested by composing with `EnglishProtoInput` in both orders and
asking foma whether the two transducers are equivalent over the admitted input
language. For every non-commuting pair a concrete counterexample is extracted as
the input projection of the relation difference `[Fwd - Rev].u` (a random
witness, shortest of a sample). None of the counterexamples is a corpus form:
the split is output-neutral on the corpus (frozen `outputs_sha256`
`aaf19ba9…480e`), so every formal non-commutation below is invisible to the 380
lexemes and is recorded on an `EnglishProtoInput`-admitted non-corpus form, as
required (formal counterexamples are not dismissed for being absent from the
corpus).

Result: **41 pairs tested, 6 non-commuting.** SC014 crosses 10 head rules
(2 non-commute); SC004 crosses 31 rules from pos 2 through SC036 (4 non-commute).

## Classification notes

1. **SC014 x PNWGmcAToUBeforeM, SC014/SC004 x PWGmcEarlyIApocope** are *feeding*
   interactions of the monophthongization into a weight-/context-sensitive rule.
   They exist because the input grammar `EnglishProtoInput` over-generates forms
   (e.g. an ending `-amai`, or a heavy `*ai` before final `-i`) that no actual
   corpus lexeme instantiates. On the corpus the two dat.sg `*-ai` witnesses
   (`span`, `meed`) sit word-finally with no following `-i` and no `*a`-before-`*m`,
   so the feedings never arise. Classified as **feeding / input-grammar artefact**.

2. **SC004 x PNWGmcILowering, SC004 x PNWGmcULowering** are *feeding* interactions
   in which the stressed vowel `*ái` versus `*ā` supplies a different conditioning
   environment for a neighbouring vowel-height rule. Again the witnesses are
   `EnglishProtoInput` forms with an `*ái` adjacent to `*i`/`*ú` in a configuration
   absent from the 24 stressed corpus witnesses. Classified as **feeding /
   input-grammar artefact**.

3. **SC004 x OEInterStressRaising (SC036)** is the one **genuine historical
   dependency**: SC004 must precede interstress raising, exactly the `soul`
   `*sáiwalō > sāwol` relation. The formal witness `rgái-ladu` reproduces it on a
   non-corpus form; the corpus witness is `soul` in the full cascade (see the
   SC004 chronology card). This is a real ordering constraint, not an artefact.

None of the interactions is *bleeding*, *marker-related* or a *stress-annotation
artefact*: the stress mark on `*ái` is intrinsic to the rule's conditioning (it
is what distinguishes SC004 from SC014), not an annotation mismatch, and no
counterexample turns on a boundary or weight marker.

## Whole-language non-equivalence, reconsidered

The previous implementation gave SC004 an unrestricted `{*ai} -> {*ā} || _ ?`
nonfinal branch (an artefact of the PROTO-based misclassification of `loam` and
`whine`). That branch made SC004 rewrite *unstressed* nonfinal `*ai` as well,
enlarging its whole-language non-commutation set (every unstressed-`*ai`
environment became an SC004 interaction). The corrected stressed-only rule
`{*ái} -> {*ā}` removes that surface: SC004 now interacts formally with only the
four rules above, all through the stressed vowel it actually targets, and all on
non-corpus inputs. SC014's non-commutations likewise reduce to the two feedings
of the monophthong into weight-/context-sensitive rules. The historically
cleaner rule pair is therefore also the formally narrower one.
