## Possible split options

### Option A: Keep SC049-SC052 as one scaffold only

This remains good for visibility because it keeps the whole onset/palatalization
zone assembled in one place. It is still a weak production shape, however,
because the row mixes one residual one-sided allophony card (`SC049`), one
later-boundary-only left-edge rule (`SC050`), one strong self-contained
palatalization candidate (`SC051`), and one central hinge rule (`SC052`) whose
best structural partner is not obvious yet.

### Option B: Promote SC050-SC052 as a narrow Sievers-law/velar-palatalization pair

This captures the reciprocal `stretch` relation and gives `SC052` a clean left
edge. It also lines `SC052` up directly with the already promoted `SC055`
boundary on the right. The weakness is that it may underplay `SC051`, which has
broader and cleaner two-sided evidence than `SC050`.

### Option C: Promote SC051 as a standalone or narrow sk-palatalization report

This is the cleanest immediate candidate on current card evidence. `SC051` has
good two-sided local boundaries, a clear lexeme set, and a historically legible
rule label. It would still need literature and book dossiers first, but it is
already easier to imagine as a narrow production report than the whole mixed
`SC049-SC052` cluster.

### Option D: Promote SC051-SC052 as a broader palatalization pair

This is historically attractive because both rules belong to the same broader
palatalization/fronting neighborhood. The problem is that the card evidence does
not make them a simple reciprocal pair. `SC051` is bounded by `SC046` and
`SC056`, while `SC052` is bounded by `SC050` and `SC055`. That asymmetry makes
the pair plausible but not yet clearly the best first promotion choice.

### Option E: Recombine SC052 and SC057 in a later j-cluster / palatalization-side unit

`SC057` has its positive boundary across `SC052`, and its witness set (`bow`,
`follow`, `hedge`, `seek`, `singe`) points structurally back toward this same
region. That makes a later `SC052`/`SC057` recombination or cross-reference
worth keeping in mind. It does **not** justify splitting the current `057-058`
row in this task, but it does mean `SC057` should stay explicitly flagged for
later reconsideration with the palatalization/fronting region.

### Option F: Leave SC049 as residual bridge material

`SC049` has real evidence, but it is narrow and one-sided, with `rainbow`
carrying the current result. That makes it worth preserving as contextual bridge
material inside the scaffold, but not a strong near-term production candidate.

## Recommended next action

The most practical next task is to prepare literature and book dossiers for
`SC051` as the clearest self-contained palatalization candidate inside the
current mixed scaffold. The whole `SC049-SC052` cluster should **not** be
promoted unchanged. `SC049` should remain scaffolded as residual bridge
material, while `SC050` and `SC052` should stay grouped at scaffold level until
later review decides whether `SC052` belongs best in a narrow `SC050-SC052`
pair or in a broader palatalization-side unit. `SC057` should remain scaffolded
for now, but it should stay explicitly marked for later reconsideration with
the palatalization/fronting region. `SC058` should remain untouched as residual
boundary-limited material.
