# Opening vowel prelude

### Sound-change report

#### Historical formulation

This scaffold unit groups `SC014` and `SC015` as the opening ordinary Northwest
Germanic vowel prelude before the better-documented `SC016-SC020` corridor. It
is a buildable placeholder rather than finished chapter prose.

#### Current evidence

Chronology cards and FOMA implementations already exist for both member changes.
No dedicated literature dossier is yet attached to this unit in the production
layer, so the scaffold keeps the opening pair visible without overstating the
present prose maturity.

#### Place in the cascade

The unit spans current cascade orders 14-15, from `NWGmcUnstressedAiMonophthongization`
to `NWGmcILowering`. In the assembled half it functions as a short prelude to
the existing `016-020` pilot corridor.

#### Order evidence

`SC014` remains largely negative and boundary-limited, while `SC015` has the
clearer broad/far profile. The scaffold therefore records an opening zone, not
yet a settled local chapter corridor.

#### Status

This is a scaffold placeholder, not finished book prose. It still needs
literature dossier work and human review of whether `SC015` eventually remains
grouped with `SC014` or splits forward into a larger early-vowel chapter.
