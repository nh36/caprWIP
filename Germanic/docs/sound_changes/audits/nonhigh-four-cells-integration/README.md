formal synthetic probes, not reconstructed attested lexical witnesses.

1. Give the productive unprefixed parse priority over the prefixed parse,

2. Additionally require an actual vowel in the productive root network.
   The reused native heavy-root expression has an optional parenthesized
   long-vowel/diphthong term; the second candidate uses mandatory square
   brackets, without changing that inherited native network.
