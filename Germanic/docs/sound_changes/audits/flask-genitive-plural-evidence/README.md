# Flask genitive-plural evidence

Reference `77f314bf85035c23706b6b09b3a1855aa23c0620`; production and
the protected selected row remain unchanged. This experiment followed
the completed seven-variant SC051 comparison, without adopting its
proposed changes.

Run `experiment.py` from the repository root with the canonical backend
available. It freezes source, corpus, contexts, pipeline, compiler,
probes and driver. Completed snapshot IDs are immutable; use a new ID
for a fresh replay. `probes.tsv` distinguishes complete raw attempts,
quantity-shadow diagnostics, literal PWGmc-vowel encodings and late
intermediates. `stage_traces.tsv` preserves every checkpoint;
`corpus_outputs.tsv` gives every selected output; `execution.json`
records source/image/log digests and authentic execution status.
No restricted original is copied into this directory.

`carrier_sensitivity/experiment.py` runs after the first experiment,
using its sealed inputs, and tests the immediately following trimoric
carrier in ordinary nonhigh syncope. It publishes the same evidence
tables plus the full394 delta. The three post-syncope -ana probes
explicitly presuppose analogical restoration; they are not adopted
transponents. No diagnostic match is described as normal raw admission.
