## Reproduction and limits

The archived `snapshot/worker.py --worker SNAPSHOT_DIRECTORY` requires the
pinned baseline source, the recorded helper hashes, a manifest-validated
baseline runtime and its container dependencies. Stage a verified snapshot
into the backend's private temporary directory and execute that exact
worker there, capturing the command with `adjudication_control.run_logged`.
Its source-identity assertions intentionally reject an unannounced replay
against the later input-gate source. Use a separate baseline checkout and
backend environment for historical replay; do not overwrite a shared
live runtime. The archived results are historical executions, not a claim
that portable CI reruns them. Routine tests authenticate the records and
check current production bins instead.
