Style conventions for the CAPR Germanic reader-facing materials

1. Bibliographic section locators

- Use § for a single section (example: §5.2) and §§ for ranges or multiple sections (example: §§145–146).
- Do not use "sect.", "sects.", "sect", "sects", "section" or "sections" as bibliographic locator labels inside citation locators. Use explicit § markers in citation suffixes (e.g., [@Campbell1959, §332]).

2. Predicted (counterfactual) model outputs

- Mark any concrete lexical form that is the product of a counterfactual model manipulation with a raised superscript dagger immediately before the form. The canonical source notation is a Pandoc span with class "pred" applied to the italic form: [*ġoc*]{.pred}
- In LaTeX output this renders as a superscript dagger immediately before the italicized form. A LaTeX macro \Pred is available as an alternative: \Pred{ġoc}.
- Document the dagger in the chronology methods: it indicates a form generated by a counterfactual chronology and not independently attested or tested.
- .pred forms are exempt from the paragraph-first gloss requirement.

3. Reconstructed lexical forms

- Reconstructed lexical forms (Proto-Germanic or other historically reconstructed words) use the .recon span class:
    [júką]{.recon}
- The reconstruction asterisk is supplied by the renderer (\Recon macro); do NOT type a leading '*' inside the span content.
- Renders as: *júką (italic, with asterisk from the macro).
- On first occurrence in each prose paragraph, a .recon form requires an English gloss immediately following it (same rule as for ordinary lexical forms).
- Repeated occurrence of the same form later in the same paragraph does not require a second gloss.
- The same form in a new paragraph requires its gloss again.
- Leave phonological/segmental notation (e.g. \emph{*u}, \emph{*ō}, \emph{*z}, \emph{*ai}, \emph{*lþ}, suffix notation *-um, schematic sequences) as raw \emph{*...} — these are NOT lexical words and should not use .recon.
- The distinction: if the form can reasonably receive an English lexical gloss, use .recon; if it is a segment, morpheme, environment, or rule symbol, leave it as \emph{*...}.

4. Paragraph-level glosses

- On first mention in each prose paragraph, every lexical linguistic form must include a brief English gloss immediately following it. A paragraph reset requires repeating glosses.
- Gloss form example: *ġeoc* 'yoke' or [júką]{.recon} 'yoke'.
- This rule applies to reader-facing prose paragraphs (Part I sound-change chapters and Part II lexical derivation prose). It does not apply to tables, code blocks, headings, index entries, bibliography entries, or derivation traces.
- Explicitly recognised lexical markup types: .iv spans, .recon spans, plain Markdown *italic* in prose.
- .pred forms are exempt from this rule.

Enforcement

- The build includes checks to detect source-level literal "sect/sects" tokens, unmarked predicted forms, and paragraph-level missing glosses. These checks are enforced in the book build pipeline and fail the build if violations are present.

Implementation notes

- Use [form]{.recon} for reconstructed lexical forms (asterisk supplied by renderer).
- Use [*form*]{.pred} for counterfactual model outputs (dagger supplied by renderer).
- Use [*form*]{.iv ...} for indexed attested/normalised Old English forms.
- Use plain *form* Markdown italic for attested Old English forms in prose that need no index entry.
- `.iv` (indexing) and `.recon` (reconstruction) are orthogonal and may coexist: [form]{.recon .iv lang=pgmc display=*form sort=...} produces the asterisk via \Recon and an index entry via .iv, with no duplication.
