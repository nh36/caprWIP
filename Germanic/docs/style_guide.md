Style conventions for the CAPR Germanic reader-facing materials

1. Bibliographic section locators

- Use § for a single section (example: §5.2) and §§ for ranges or multiple sections (example: §§145–146).
- Do not use "sect.", "sects.", "sect", "sects", "section" or "sections" as bibliographic locator labels inside citation locators. Use explicit § markers in citation suffixes (e.g., [@Campbell1959, §332]).

2. Predicted (counterfactual) model outputs

- Mark any concrete lexical form that is the product of a counterfactual model manipulation with a raised superscript dagger immediately before the form. The canonical source notation is a Pandoc span with class "pred" applied to the italic form: [*ġoc*]{.pred}
- In LaTeX output this renders as a superscript dagger immediately before the italicized form. A LaTeX macro \Pred is available as an alternative: \Pred{ġoc}.
- Document the dagger in the chronology methods: it indicates a form generated by a counterfactual chronology and not independently attested or tested.

3. Paragraph-level glosses

- On first mention in each prose paragraph, every lexical linguistic form must include a brief English gloss immediately following it. A paragraph reset requires repeating glosses.
- Gloss form example: *ġeoc* 'yoke' or *ġeoc* “yoke”.
- This rule applies to reader-facing prose paragraphs only (not tables, code blocks, headings, index, or bibliographic entries).

Enforcement

- The build includes checks to detect source-level literal "sect/sects" tokens, unmarked predicted forms, and paragraph-level missing glosses. These checks are enforced in the book build pipeline and fail the build if violations are present.

Implementation notes

- Use [*form*]{.pred} when authoring counterfactual predicted outputs. The project includes a Lua filter / Pandoc-to-LaTeX macro pair to render this consistently.
