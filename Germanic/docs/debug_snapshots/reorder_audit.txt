**Critical observation**: The TSV has NO Old_English PROTOFORM ending in
bare `a` (grep shows zero matches for `[^aąăōo]a$` or `á$`). Every word-
final *a at retraction time is the result of:

  (a) PGmcFinalOZShortening: *-ōz → *-a (f.ō-stems, some others);
  (b) PGmcFinalZDeletion from *-az (m.a-stem nom.sg.).

R/T §§3.1-3.4 is explicit that **BOTH** of these word-final *-a
outcomes are lost in PWGmc, before AFB. The current FST keeps them
around because they were historically invisible to AFB/retraction
anyway (since the trigger set excluded {*ă}, and historically final
*a had been lost). Post-migration, bare {*a} is in the trigger set
and now these historical ghosts cause over-triggering.

## A1: rules between OEARestoration and OEFinalSchwaApocope that depend
## on word-final weak-tail shapes

Survey of lines 2629 → 2644:

line 2629   OEARestoration                — fires on back V in next σ.
line 2641   OEHeavySyllableNasalApocope   — deletes infinitive *-ąˈ.
line 2643   OESecondaryNasalization       — nasalises *V before coda *n.

These rules operate on distinct material:
- OEHeavySyllableNasalApocope targets {*ą}ˈ (nasal vowel with stress
  marker, infinitive ending) — NOT bare {*a}.
- OESecondaryNasalization targets *V{*n} in coda position — needs the
  output of apocope, not of final-a loss.
- OEARestoration is the rule we're trying to fix.

**Conclusion**: no rule between retraction and apocope depends on
bare word-final {*a} surviving. Moving a final-bare-a deletion earlier
(before AFB) is safe with respect to this block.

## Proposed reordering (Option X)

1. Split `OEFinalSchwaApocope` into two rules:

   ```
   define PWGmcFinalBareALoss [
       {*a} -> 0 || _ .#.
   ];

   define OEFinalSchwaApocope [
       {*ă} -> 0 || _ .#.
   ];
   ```

2. In `EnglishProtoToOE`, insert `PWGmcFinalBareALoss` before AFB:

   ```
   .o. OEPrefixAReduction
   .o. OEInterStressRaising
   .o. PWGmcFinalBareALoss   <-- NEW POSITION
   .o. AngloFrisianBrightening
   .o. OEBreaking
   .o. OEVelarFricativePalatalization
   .o. OEARestoration
   ...
   .o. OEFinalSchwaApocope   <-- now only handles stray {*ă}
   ```

3. Mirror the change in the trace stack (`EnglishAfterProtoToOE*`).

### Key question: were any word-final bare `a` (from *-az, *-ōz)
### acting as TRUE retraction triggers for a preceding æ?

Case analysis:

(i) Nom.sg. m.a-stem *-az (→ *-a):
    — input like *dagaz, *bardaz, *stabaz.
    — at retraction time (historical): no tail at all (R/T: already
      lost in PWGmc) → no retraction → OE *dæg, *beard, *stæf.
    — Empirical OE forms: *dæg, *beard, *stæf ✓ (MATCHES R/T).
    — With PWGmcFinalBareALoss before AFB: final -a deleted → no
      trigger → AFB gives *dæg → correct.
    — Under current pipeline: final -a present at retraction → false
      trigger → *dag (wrong). This IS the regression.

(ii) Nom.sg. f.ō-stem *-ōz (→ *-a via PGmcFinalOZShortening):
    — input like *gebōz → *geba; *skapaną (unrelated); *laiβō (if any).
    — Historical OE nom.sg. f.ō-stems: *geofu, *gifu, *lufu etc.
    — f.ō-stem nom.sg. in OE ended in *-u or *-Ø. The pre-OE stage
      had *-ō / *-u, not *-a. R/T §3.1.1 (our line 1017-1022): f.ō-
      stem nom.sg. *-ōz → *-a as the PWGmc outcome, but this *-a
      was lost word-finally BEFORE AFB (that's the same PWGmc final
      loss).
    — So for f.ō-stems, final -a at retraction time should also be
      absent. Option X correctly deletes it early.
    — Check our TSV: grep finds ZERO OE PFs ending in bare `a`
      (already confirmed above), so this case is empirically empty
      — but defending the rule for when it does arise is still
      required for compound-linking and other inputs.

(iii) Medial (non-final) bare `a`:
    — PWGmcFinalBareALoss has context `_ .#.` — word-final only.
    — Medial bare `a` (e.g. *daga-, *stapula-, *wirald-) is NOT
      affected. These remain available as retraction triggers
      where they genuinely are (e.g. gen.pl. *dagō → still has *ō,
      not *a; weak II *makōj- still has *ō).
    — So there's no collateral damage to medial triggers.

### Verdict

Option X is surgical and safe. The new `PWGmcFinalBareALoss` rule
deletes only word-final bare `{*a}` that arose from PGmc *z-loss,
matching R/T's PWGmc chronology. It removes the false-trigger
problem for A-restoration without disturbing any medial back vowel
that genuinely should trigger retraction.

## Remaining question: interaction with OESecondaryNasalization
## and OEHeavySyllableNasalApocope (infinitive chain)

Infinitive *-aną → PGmcFinalZLoss (no *z, unchanged) → PWGmcChanges
(no denasalization) → ... → AFB: unstressed *a in *-ąˈ → does AFB
fire on the -a- in -aną? Check the rule.

Pre-migration AFB targets stressed *á and specific unstressed *a
contexts. Post-Phase 1d-β AFB split (§17.10.13): unstressed AFB
applies only word-medially (not word-finally). So *-aną is safe.
OEHeavySyllableNasalApocope then converts *-ąˈ to Ø, followed by
OESecondaryNasalization.

Under Option X, we DO NOT touch *-aną: our new rule only deletes
word-final bare `{*a}`, not `{*ą}`. So the infinitive chain is
unaffected.
