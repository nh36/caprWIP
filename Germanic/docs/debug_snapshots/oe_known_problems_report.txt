--- smoothing_anglian_relic (1) ---
  *ráukaz            -> rēac                 (expected rēc)
    reason: OE rēc has velar [k] (per ModE reek /riːk/, not /iːtʃ/). Etymon switched from i-stem *ráukiz to a-stem *ráukaz (Kroonen, p.c.; analogical replacement; cf. Ger. Rauch). FST output rēac is regular; rēc requires Anglian smoothing (ēa→ē / _velar) which is dialectally restricted — adding it as a cascade rule would regress WS bēacen, hēah, ēage, sēah, tēah. Treated as Anglian relic loaned into WS, no FST fix.
    refs:   notable_findings#10;DEV_NOTES.md §17.22;dossier-reek-2026.md
    added:  2026-04-26
