## Style target

This pilot aims at a middle style between compression-pilot Variant B and Variant C. The new prose is shorter than Variant B because it does not preserve the report-export section structure, but it is more explanatory than Variant C because each entry still gets newly drafted commentary rather than a near-silent trace-only presentation.

The prose is written from the existing model-entry content, not copied section by section. Citations were retained where the underlying claims were kept, but no new sources or new locators were introduced. The trace boxes, derivation summaries, citation links, and Unicode-safe rendering were reused unchanged from the successful full-volume assembly layer.

## Editorial issues

- **both / bū**: the compact note works better than a pasted table, but the wider relation between neuter dual *bū*, masculine *bēġen*, and the later history of English *both* still wants a house editorial policy.
- **learn / liornian**: the Northumbrian choice is intelligible in compact form, but this remains the clearest case where dialect targeting may need a recurring editorial formula.
- **mother / mōder**: the pilot keeps the regular nominative argument, but a production rollout should decide how prominently later levelled dictionary forms such as *mōdor* must remain visible.
- **weapon / wǣpn**: the compact prose preserves the unbroken/broken distinction, but this is still a place where readers may expect more explicit signalling that the book target is not the usual headword form.
- **show / sċēawian**: the compact form note works, but it slightly exceeds the simple-entry target range and may still be compressible by one more sentence-level pass.

## Recommendation

**B. The style is close but needs another sample revision.**

The pilot succeeds as proof of concept: it reads more like monograph prose than Variant B, while preserving substantially more explanation than Variant C. But the comparison-heavy and dialect-sensitive entries still need one more editorial pass to settle recurring house decisions before this style is applied to all regular entries.
