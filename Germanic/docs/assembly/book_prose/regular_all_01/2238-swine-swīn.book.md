Kroonen cites the noun as _\*swina-_ 'pig' [@Kroonen2013, 542]. The selected comparative form here is the bare neuter citation cell _\*swī́ną_, which matches the singular noun aimed at in Old English rather than an oblique stem form. Clark Hall records _swin (y)_ as the ordinary noun headword [@ClarkHall1960, 301]. From selected input _\*swḯną_, loss of the final nasal vowel yields _swīn_.

Source note. The selected input writes stressed long _ī_ as _\*ḯ_, so comparative _\*swī́ną_ and derivational _\*swḯną_ represent the same lexical form.
