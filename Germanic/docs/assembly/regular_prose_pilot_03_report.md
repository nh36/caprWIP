## Prose style changes

Pilot 02 had acceptable size and structure, but too much meta-editorial phrasing. Pilot 03 keeps the same compact one-paragraph or short-note format and recasts the commentary as direct factual prose: reconstruction, Old English evidence, dialect or spelling variation where relevant, and the reason the selected form is regular.

Citations were preserved where the underlying claims remain. No new sources or locators were added. The trace boxes, derivation summaries, links, and Unicode-safe rendering continue to use the current full-assembly layer unchanged.

## Removed phrase types

Pilot 03 removed the main meta or self-conscious phrase types from pilot 02:

- references to “the prose”
- references to “the book”
- “editorial issue”
- “point of compression”
- “may deserve”
- overuse of colons
- rhetorical contrast and explanatory framing of the form “the issue is not X but Y”
